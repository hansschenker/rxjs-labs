# Patterns

Explore common reactive patterns we use in experiments:

- **Stream composition:** Combine observables with `merge`, `concat`, and `combineLatest` for flexible data flows.
- **Error handling:** Apply `catchError` and `retry` strategies to improve resilience.
- **Resource management:** Use `takeUntil` and `finalize` to clean up subscriptions.

Each pattern links to practical examples and code snippets to help you get started quickly.
